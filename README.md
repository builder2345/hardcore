# 나락 강하

어둡고 무거운 하드코어 2D 횡스크롤 생존 게임. 웹소설 「게임 속 바바리안으로 살아남기」의 미궁·정수 구조와 분위기를 바탕으로, 파이널 데스티니식 이형/층주/재앙 보스 체계와 IDLEON식 도시 서브컨텐츠를 섞었다. 원작 고유명사는 전부 대체어를 쓴다.

브라우저에서 바로 돈다. 빌드 과정은 없다.

## 실행

- `index.html`을 브라우저로 열면 된다.
- 로컬 서버로 열어도 된다: `npx http-server -c-1 .` 후 `http://localhost:8080`
- 키보드 전용. 진행은 브라우저 localStorage에 자동 저장된다 (메뉴 → 저장에서 문자열로 내보내기/불러오기).

## 조작 (메이플식 배치)

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| Space / C | 점프 (공중에서 한 번 더) |
| ↑ ↓ | 밧줄 오르내리기, ↑ 로 포탈·건물 문 |
| ↓ + Space | 발판 아래로 내려가기 |
| X | 공격 (연타하면 콤보) |
| Z / Shift | 회피 (짧은 무적, 기력 소모) |
| A S D F | 영혼 스킬 |
| Q | 물약 |
| E | 채집·숨은 조각 파기 |
| R | 모닥불 곁에서 휴식 (시간 가속, 기습 위험) |
| T | 탈출 부적 (6초 집중) |
| I / K / M / Esc | 장비·가방 / 영혼 / 지도 / 메뉴 |

## 핵심 규칙

- **나락(미궁)**: 도시 '카르덴'의 강하 광장에서 내려간다. 층마다 닫히는 날이 정해져 있고(나락의 하루 = 실제 60초), 닫히는 순간 살아 있는 탐색자는 들고 있던 것과 함께 도시로 뱉어진다.
- **층 구조**: 강하 지점(허브)에서 동서남북 네 갈래. 네 갈래 끝 중 한 곳에만 다음 층 포탈 비석이 열린다(강하마다 무작위).
- **죽음**: 다시 시작하지는 않는다. 대신 들고 있던 흑석·재료·영혼 구슬·물약을 전부 잃고, 경험치가 깎이고, 다음 강하에서 최대 체력 -25%(중상).
- **영혼**: 몬스터가 드물게 남긴다. 흡수하면 능력치(좋은 것과 나쁜 것이 섞여 있다) + 패시브 + 색깔에 따른 액티브를 얻는다. 레벨 수만큼만 담을 수 있고, 같은 몬스터의 영혼은 둘 담을 수 없다. 탐색자 등급은 담은 영혼의 총량으로 정해진다.
- **보스 계층**: 조건과 확률이 맞아야 나오는 **이형** < 깨어나면 층 전체를 잠식시키고 필드 효과를 거는 **층주** < 층주를 쓰러뜨린 적이 있어야 깨어나는 **층의 재앙**. 드물게 열리는 **열극**에 들어가면 파수꾼을 죽이기 전엔 못 나온다(무지개 영혼·각인 유물·열극석).
- **도시 서브컨텐츠**: 채집(폐갱도·고사목 숲·검은 우물, 일꾼 방치 수확), 대장간(제작·+10 강화·파괴 위험), 연금(영약 솥·물약 양조), 요리, 혈문 각인, 위령비, 서약(축복+저주), 사냥 장부(별 단계 보너스), 정보상, 은신처 증축, 교환소.

## 폴더 구조

```
index.html, css/style.css
js/core      입력, 오디오(WebAudio 합성음), 스프라이트 로더
js/data      스탯·스킬·몬스터·층·아이템·서브컨텐츠·아트 배정표 (assets.js는 자동 생성)
js/world     맵 생성기, 충돌, 지형/배경 렌더
js/entities  플레이어, 적 AI·공격 라이브러리, 효과, 그리기
js/game      전투, 스킬, 구역, 강하, 도시, 서브컨텐츠, 저장
js/ui        HUD, 패널
assets/      스프라이트 스트립, 타일셋, 배경, 소품 (CREDITS.md 참고)
tools/build_assets.py  원본 에셋 팩에서 assets/를 다시 만드는 스크립트
```
