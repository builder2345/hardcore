# 나락 강하

어둡고 무거운 2D 횡스크롤 생존 게임이에요. 도시 카르덴의 강하 광장에서 나락으로 내려가, 층이 닫힐 때까지 버티고 살아서 돌아오는 게 전부예요. 죽는다고 처음부터 다시 하진 않지만, 그 대가가 꽤 커요.

브라우저에서 바로 돌아가고 빌드 과정은 없어요.

## 실행

`index.html`을 브라우저로 열면 돼요. 로컬 서버로 열고 싶으면 `npx http-server -c-1 .`을 띄운 뒤 `http://localhost:8080`으로 들어가면 되고요.

키보드로만 할 수 있어요. 진행 상황은 브라우저 localStorage에 알아서 저장되고, 다른 브라우저로 옮기려면 메뉴의 저장 항목에서 문자열로 내보내고 불러오면 돼요.

## 조작

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| Space / C | 점프, 공중에서 한 번 더 |
| ↑ ↓ | 밧줄 오르내리기, ↑로 포탈과 건물 문 |
| ↓ + Space | 발판 아래로 내려가기 |
| X | 공격, 연타하면 콤보 |
| Z / Shift | 회피 (짧은 무적, 기력 소모) |
| A S D F | 영혼 스킬 |
| Q | 물약 |
| E | 약초 채집, 묻힌 것 파내기 |
| R | 모닥불 곁에서 쉬기 (시간이 빨리 가지만 기습당할 수 있음) |
| T | 탈출 부적 (6초 동안 집중) |
| I / K / M / Esc | 장비와 가방 / 영혼 / 지도 / 메뉴 |

떨어진 물건은 몸에 닿으면 저절로 주워져요.

## 어떻게 돌아가나

층마다 닫히는 날이 정해져 있어요. 나락의 하루는 실제 60초고, 층이 닫히는 순간까지 살아 있으면 들고 있던 걸 그대로 가지고 도시로 내던져져요. 강하 지점에서 길이 동서남북 네 갈래로 갈리는데, 다음 층으로 가는 포탈 비석은 그중 한 곳 끝에만 열려요. 어디가 열릴지는 내려갈 때마다 달라져요.

죽으면 그때까지 모은 흑석, 재료, 영혼 구슬, 물약을 전부 잃고 경험치도 깎여요. 다음 강하는 최대 체력이 25% 깎인 중상 상태로 시작해요. 잡화점에서 치료하거나 그다음 강하를 무사히 마쳐야 풀려요.

몬스터는 흑석을 남기고, 아주 드물게 영혼을 떨어뜨려요. 영혼을 몸에 담으면 그 몬스터의 능력치와 패시브, 색깔에 따라 다른 액티브 스킬을 얻는데, 능력치엔 손해 보는 항목도 섞여 있어요. 담을 수 있는 개수는 레벨과 같고, 같은 몬스터의 영혼을 두 개 담을 수는 없어요. 탐색자 등급은 담은 영혼의 무게로 정해져요.

층마다 보스가 세 겹으로 깔려 있어요. 이형은 특정 조건을 채운 뒤에도 확률이 맞아야 튀어나와요. 층주는 정해진 날이 지나고 피가 충분히 흐르면 깨어나는데, 깨어나는 순간 층 전체 몬스터가 잠식종으로 바뀌고 층마다 다른 필드 효과가 걸려요. 층의 재앙은 그 층의 층주를 한 번이라도 쓰러뜨린 뒤에야 깨어날 수 있어요. 가끔 붉은 열극이 열리는데, 한번 들어가면 파수꾼을 죽이기 전엔 못 나와요. 그래서 깊이 내려간 뒤에도 앞 층에 숙제가 남아요.

도시에선 채집지에 일꾼을 보내 두면 꺼 둔 사이에도 재료가 쌓이고, 대장간에선 장비를 만들고 +10까지 강화할 수 있어요(높은 단계에선 부서질 수 있어요). 그 밖에 연금 솥, 요리, 혈문 각인, 위령비, 축복과 저주를 함께 주는 서약, 사냥 장부, 정보상, 은신처 증축, 교환소가 있어요.

## 폴더 구조

```
index.html, css/style.css
js/core      입력, 오디오(WebAudio 합성음), 스프라이트 로더
js/data      스탯, 스킬, 몬스터, 층, 아이템, 서브컨텐츠, 그림 배정표 (assets.js는 자동 생성)
js/world     맵 생성기, 충돌, 지형과 배경 그리기
js/entities  플레이어, 적 AI와 공격 패턴, 효과, 그리기
js/game      전투, 스킬, 구역, 강하, 도시, 서브컨텐츠, 저장
js/ui        HUD, 패널
assets/      스프라이트, 타일셋, 배경, 소품 (출처는 CREDITS.md)
tools/build_assets.py    원본 에셋 팩에서 assets/를 다시 만드는 스크립트
tools/build_artifact.py  CSS와 JS를 한 페이지로 묶어 dist/naraak.html을 만드는 스크립트
```
